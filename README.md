NovaTech 💻
A modern laptop e-commerce website built with HTML, CSS, and JavaScript.
Overview
NovaTech is a fully functional front-end e-commerce store specializing in laptops. Users can browse a catalog of 30+ laptops, filter by specs, add items to a cart, and proceed to checkout — all without a backend.
Features

Browse 30+ laptops from top brands (Apple, Dell, Lenovo, ASUS, HP, Razer, and more)
Filter and search products by name, RAM, storage, and price
Add to cart and manage quantities
Persistent cart using localStorage
Checkout page with order summary
Responsive design

Tech Stack

HTML5
CSS3
Vanilla JavaScript (no frameworks)

Project Structure
NOVATECH/
├── index.html        # Main product listing page
├── checkout.html     # Checkout page
├── script.js         # Product data and cart logic
├── checkout.js       # Checkout functionality
├── style.css         # Global styles
└── images/           # Product images
